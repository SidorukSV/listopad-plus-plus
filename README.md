# Listopad++

<p align="center">
  <img src="assets/listopad-plus-plus.png" width="64" height="64" alt="Иконка Listopad++">
</p>

Listopad++ — быстрый нативный текстовый редактор для Windows 10 2004+ и
Windows 11. Он написан на C++20/Win32, быстро запускается и во время работы не
обращается к сети. В приложении нет телеметрии, новостей, рекламы, фонового
процесса, автообновления и загрузки плагинов.

Текущая версия: **0.3.0**. История изменений приведена в
[CHANGELOG.md](CHANGELOG.md).

## Возможности

- один экземпляр на пользователя Windows, вкладки и передача новых файлов уже
  запущенному редактору через локальный именованный канал;
- поддержка Unicode-путей, пробелов, UNC и путей длиннее 260 символов;
- статически встроенные Scintilla 5.6.4 и Lexilla 5.5.1: подсветка синтаксиса,
  сворачивание блоков, номера строк и ручной выбор всех штатных лексеров;
- раздельная подсветка HTML, JavaScript и CSS внутри `<style>`;
- локальная подсветка BSL (`.bsl`) и OneScript (`.os`) с кириллическими
  идентификаторами, без BSL Server и фонового языкового сервера;
- системная светлая или тёмная тема;
- внутреннее представление текста в UTF-8 со строгим распознаванием BOM и UTF,
  резервным определением устаревшей кодировки через uchardet и ручным
  переоткрытием в UTF-8, UTF-16, Windows-1251, Windows-1252 или CP866;
- сохранение исходной кодировки, BOM и типа окончания строк;
- форматирование JSON, XML и HTML как одной отменяемой операции;
- Emmet 2.4.11 для HTML/XML/JSX и CSS-подобных языков на лениво создаваемом
  экземпляре среды выполнения QuickJS-NG;
- неблокирующий поиск и замена на PCRE2 10.47 с UTF/UCP/JIT, регулярными
  выражениями,
  `$0`/`$1…$99`/`${name}`, поиском по выделению и всем вкладкам;
- включаемая карта документа с подсветкой синтаксиса, индикатором видимой
  области и навигацией по клику;
- шестнадцатеричный/ASCII-просмотр бинарных файлов только для чтения с
  отображением файла в память, байтовым поиском и ручным переключением
  текстового представления;
- фильтры типов файлов в диалоге сохранения и автоматическое расширение по
  выбранному языку для нового документа;
- реакция на внешнее изменение файла с явным выбором «Перезагрузить» или
  «Оставить» и защитой от перезаписи более новой дисковой версии;
- атомарное сохранение и брокер UAC: защищённый файл сохраняется после одного
  запроса UAC без перезапуска редактора и повторного поиска файла;
- виртуализированный режим только для чтения для файлов от 128 МиБ с
  отображением файла в память и асинхронным поиском;
- отдельное представление технологического журнала 1С: автоматическое
  распознавание, фоновая индексация, фильтры событий, понятные описания полей
  и скрываемая исходная запись для проверки интерпретации;
- отдельное представление журналов системного монитора Windows: бинарные
  `.blg` через системный PDH и текстовые экспорты `(PDH-CSV 4.0)` и
  `(PDH-TSV 4.0)`, таблица счётчиков со статистикой, фильтры, график по
  времени, оценка по явным порогам и скрываемая таблица всех отсчётов;
- восстановление открытых вкладок, активной вкладки, курсора и прокрутки после
  штатного завершения;
- фоновые аварийные снимки несохранённого текста с проверкой SHA-256 и
  безопасным восстановлением после сбоя;
- списки недавних и закрытых файлов, включая **Ctrl+Shift+T**;
- единый диалог настроек для интерфейса, редактора, больших файлов, сеанса и
  recovery;
- классическое контекстное меню через реестр Windows; в Windows 11 команда
  находится в разделе «Показать дополнительные параметры».

В текущую реализацию не входят поиск по каталогам, сравнение и слияние файлов,
плагины, LSP, автодополнение и автообновление.

## Командная строка

```text
ListopadPP.exe [--line N[:M]] [--encoding NAME] <file...>
ListopadPP.exe --register-context-menu
ListopadPP.exe --unregister-context-menu
```

Примеры кодировок: `utf-8`, `utf-8-bom`, `utf-16le`, `utf-16be`,
`windows-1251`, `windows-1252` и `cp866`.

Команды `--register-context-menu` и `--unregister-context-menu` управляют
классическим HKCU-пунктом переносной сборки. MSI устанавливает такой же пункт для
всех пользователей через HKLM. Современная команда верхнего уровня Windows 11
не регистрируется.

## Сборка

Требования:

- Windows x64;
- Visual Studio 2022 Build Tools с MSVC;
- Windows 10/11 SDK;
- CMake 3.29+, Ninja, Git и PowerShell 7 либо Windows PowerShell.

Зависимости закреплены в `vcpkg.json`. Scintilla и Lexilla загружаются CMake из
зафиксированных источников с проверкой версии или SHA-256.

```powershell
./scripts/bootstrap-vcpkg.ps1
./scripts/build.ps1 -Preset debug
./scripts/build.ps1 -Preset release
```

Прямой эквивалент для Debug-сборки:

```powershell
$env:VCPKG_ROOT = "$PWD/.deps/vcpkg"
cmake --preset debug
cmake --build --preset debug --parallel
ctest --preset debug --output-on-failure
```

## Упаковка и подпись

Для создания MSI в дополнение к переносному ZIP-архиву установите WiX v5:

```powershell
dotnet tool install --global wix --version "5.*"
wix extension add -g WixToolset.UI.wixext/5.0.2
./scripts/package.ps1 -Version 0.3.0
```

Версию нужно указывать явно. В v4 нет элемента `<Files>`, которым описываются
наборы логотипов и лицензий, а v6 и v7 требуют принять платную лицензию
Open Source Maintenance Fee. Расширение `WixToolset.UI.wixext` обязательно:
без него не соберутся диалоги установщика.

MSI намеренно остаётся неподписанным. Подпись используется только для
`ListopadPP.exe` и `ListopadElevated.exe`: релизная сборка разрешает
UAC-сохранение, лишь когда оба файла имеют доверенные подписи одного
сертификата. Это наиболее безопасный режим: с повышенными правами работает
только узкий broker сохранения.

Покупать сертификат для работоспособности приложения не требуется.
Неподписанная сборка при отказе доступа предлагает перезапустить весь редактор
от имени администратора, восстанавливает несохранённые вкладки и повторяет
исходное сохранение. Диалог предупреждает, что в таком режиме повышенные права
получает весь редактор. Для локальной проверки подписанного broker-сценария
можно явно создать бесплатный тестовый сертификат:

```powershell
./scripts/new-dev-certificate.ps1
$password = ConvertTo-SecureString 'listopad-dev-only' -AsPlainText -Force
./scripts/package.ps1 -PfxPath ./.deps/signing/ListopadPP.Development.pfx -PfxPassword $password
```

CI производственной сборки принимает сертификат для двух PE-файлов через
защищённые секреты либо внешнюю службу подписи. Упаковщик не подписывает ни
MSI, ни переносной ZIP-архив.

В переносной сборке классическое меню регистрируется командой
**Инструменты → Зарегистрировать классическое контекстное меню**. Изменения
вносятся только в `HKCU\Software\Classes`; команда удаления полностью убирает
эту регистрацию.

## Настройки

Обычная установка хранит профиль в `%LOCALAPPDATA%\Listopad++`: настройки —
в `settings.json`, состояние вкладок — в `session.json`, аварийные снимки —
в каталоге `recovery`. Если рядом с EXE находится `portable.flag`, весь профиль
хранится в каталоге приложения; recovery-файлы там не шифруются.

Основные параметры: `uiLanguage` (`ru`/`en`), `theme`
(`system`/`light`/`dark`), `fontFace`, `fontSize`, `indentSize`,
`indentWithTabs`, `documentMap`, `largeFileThreshold` в байтах,
`recoveryEnabled`, `restoreSession`, `recoveryMaxBytes` и
`recoveryRetentionDays`. Их можно менять через
**Инструменты → Настройки…**.
