# История изменений

В этом файле фиксируются заметные изменения Listopad++. Версии следуют
[семантическому версионированию](https://semver.org/lang/ru/).

## [0.1.1] — 2026-07-22

Первый публичный выпуск редактора.

### Добавлено

- нативное 64-битное приложение на C++20/Win32 без тяжёлого UI-фреймворка,
  фонового процесса, телеметрии и сетевой активности во время работы;
- один экземпляр на пользователя, вкладки и передача путей повторного запуска
  через версионированный локальный named pipe;
- открытие Unicode-, UNC- и long paths из командной строки и Проводника;
- статически встроенные Scintilla 5.6.4 и Lexilla 5.5.1, номера строк,
  folding, светлая и тёмная темы;
- подсветка штатных языков Lexilla, раздельная HTML/JavaScript/CSS-подсветка и
  ручной выбор языка;
- локальный лексер BSL и OneScript для `.bsl` и `.os` без BSL Server;
- распознавание BOM, UTF и legacy-кодировок, ручное переоткрытие в кодировке,
  сохранение исходных BOM, кодировки и EOL;
- форматирование JSON, XML и HTML с сохранением исходного текста при ошибке;
- Emmet 2.4.11 на лениво создаваемом QuickJS-NG runtime с tabstops;
- неблокирующий обычный и regexp-поиск/замена на PCRE2 с UTF/UCP/JIT,
  ограничениями ресурсов и областью «все вкладки»;
- отслеживание внешних изменений файла с вариантами «Перезагрузить» и
  «Оставить», защитой dirty-документа и проверкой fingerprint перед сохранением;
- атомарное сохранение и сессионный UAC-broker без перезапуска редактора;
- read-only large-file mode с memory mapping для файлов от 128 МиБ;
- классическое контекстное меню HKCU и современная команда Windows 11 через
  изолированную `IExplorerCommand` DLL и sparse identity package;
- русская и английская локализация интерфейса;
- portable ZIP, MSIX identity package, MSI через WiX v4 и единая схема подписи
  PE/MSIX/MSI;
- GitHub Actions для Debug/Release CI и ручной или теговый выпуск релиза с
  SHA-256 checksums;
- фирменная multisize-иконка для приложения, UAC-helper, Проводника и пакетов.

### Исправлено

- согласованы цвета элементов интерфейса и редактора в светлой и тёмной темах;
- исправлено исчезновение текста после прокрутки в светлой теме;
- устранена белая рамка редактора в тёмной теме;
- улучшены размеры вкладок, добавлены отдельные кнопки закрытия;
- исправлена отрисовка кнопок и отступов панели внешнего изменения файла;
- HTML-форматтер сохраняет автономные пользовательские элементы и не изменяет
  документ при ошибке;
- исправлена подсветка HTML, CSS внутри `<style>` и JavaScript внутри
  `<script>`;
- исправлена локализация классического и современного контекстного меню;
- устранено дублирование команды «Открыть в Listopad++» при установке
  современного sparse identity package;
- упаковщик больше не повреждает рабочий portable-каталог, если редактор из
  него запущен: ZIP собирается из отдельного образа, а занятый каталог остаётся
  без изменений;
- добавлены прозрачные `targetsize`-ресурсы для светлой и тёмной темы, поэтому
  Windows больше не рисует цветную подложку за иконкой на панели задач и в
  меню «Пуск»;
- из самого логотипа удалена тёмно-зелёная панель: лист и символы кода теперь
  отрисовываются непосредственно на прозрачном фоне во всех PNG/ICO-размерах;
- загрузка Scintilla в CI переведена на официальный SourceForge mirror с
  резервным upstream URL и обязательной проверкой SHA-256.

### Безопасность

- UAC-broker принимает только ограниченный протокол сохранения, проверяет
  nonce, PID, подписи, fingerprint, длину и SHA-256 содержимого;
- включены атомарная замена, защита от reparse points и повторная проверка файла
  непосредственно перед записью;
- `main` защищён от прямых и force-push, удаления и merge без обязательного CI;
- в публичном репозитории включены secret scanning, push protection и приватные
  отчёты об уязвимостях.
